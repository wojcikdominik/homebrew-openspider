# homebrew-openspider

Homebrew tap for [OpenSpider](https://openspider.de/), a website crawler and analysis desktop application for macOS.

## Install

Homebrew loads casks from third-party taps only after you trust the tap explicitly:

```sh
brew tap wojcikdominik/openspider
brew trust wojcikdominik/openspider
brew install --cask wojcikdominik/openspider/openspider@beta
```

Requires macOS 13 or later. The cask installs the same signed and notarized DMG that is attached to the
[GitHub release](https://github.com/wojcikdominik/openspider/releases).

## Upgrade and uninstall

OpenSpider updates itself. An upgrade through Homebrew therefore needs `--greedy`:

```sh
brew upgrade --cask --greedy wojcikdominik/openspider/openspider@beta
brew uninstall --cask wojcikdominik/openspider/openspider@beta
```

## Source

The casks in this tap are generated by the release workflow of
[wojcikdominik/openspider](https://github.com/wojcikdominik/openspider); please report problems there.
